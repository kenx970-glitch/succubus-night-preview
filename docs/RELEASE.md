# 商用移行の条件

この版はテストに必要な経済・署名Webhook・AI・メディアを実装したローカルWebアプリです。販売事業者の承認や法的適合、実Stripe受入、運用体制まで完了した商用サービスではありません。以下を具体化した後、本番決済・現実の請求・一般公開についてユーザー承認を得てください。環境変数だけで本番へ切り替える仕組みは設けていません。

## 決済・法務

- Stripeの事業審査・コンテンツ利用可否。AIの露骨な性的サービスは提供しない。
- Sの資金決済法上の分類、自家型/第三者型の区分、発行者と利用範囲、未使用残高管理、届出・供託等の要否を日本の専門家と確認する。一般的な自家型前払式支払手段では基準日に未使用残高が1,000万円を超えた場合の手続き等があるが、本サービスへの適用を確定したものではない。
- 現在のSは有効期限なし。Appleでは購入したゲーム内通貨等を失効させてはならないため、期限で法的扱いを回避する設計を安易に流用しない。
- 特定商取引法表示、運営者・住所・電話番号・問い合わせ先、税込価格、提供時期、正式返金・サービス終了時の扱い、利用規約、プライバシーポリシーを確定する。
- 決済完了月を含む月間上限、既存Checkout取消、返金・複数紛争の充当、取得済み特典を再設計・実接続で検証する。詳細はPAYMENTS.md。
- iOSを別途作る場合はStoreKit、AndroidはGoogle Play Billingとサーバー検証・通知を実装する。このWeb版のStripe購入をネイティブ向けの規則回避として使わない。

参考： [金融庁の前払式支払手段案内](https://www.fsa.go.jp/news/27/sonota/20151214-2.html)、[中国財務局の案内](https://lfb.mof.go.jp/chugoku/kinyusyouken/kin3/purika/shouhinken0605.html)、[Apple審査ガイドライン](https://developer.apple.com/app-store/review/guidelines/)、[Google Play決済ポリシー](https://support.google.com/googleplay/android-developer/answer/9858738?hl=en)。確認基準日：2026-10-09。

## 本番インフラ・アカウント

- 承認済みのHTTPS公開先、セキュアCookie、秘密情報の管理、DBのバックアップ・復元訓練、監視と障害対応を整備する。
- ローカルではSQLiteの単一プロセスとプロセス内ロックを使用する。複数サーバー運用には共有DB・分散ロック・永続ジョブを設計する。
- アカウント復旧、アカウント削除、データ保持期限、認証防御、管理者の権限・監査、サポート窓口を実装する。
- `/api/state`の履歴は現在全件返すため、商用の長期データにはページングと保存方針が必要。
- 不正な操作で残高を変更する公開APIはない。ただしローカルDBを直接編集できる端末の管理者に対する防御ではない。

## AIと品質

- 自由会話は返答1回5Sを先に予約し、未完成で返却する。アカウント数全体のAPI予算・同時実行・請求監視は別途整備する。音声予約の起動時復旧は単一サーバーを前提とする。
- Fal自由会話は安全方針をsystem promptに固定し、別のモデル判定と表現フィルターで応答を確認する。モデルの完全な安全保証ではない。性的内容、課金拒否、依存、プロンプト改変等の実機評価と報告・停止導線を整える。
- AI・音声の不明な生成結果は同じ操作で自動再送しない。運営者がFal履歴を確認して復旧する。TTSは生成済みバイトを再利用する。
- 現行マイクはFal音声認識とGemini返答/TTS。OpenAI音声アダプターは削除済み。Gemini音声だけを使用する。音声認識の入力はサーバーから期限900秒を指定してFalへ送る。事業者の保持条件を正式なプライバシーポリシーへ反映する。
- 現在は短い生成待機映像とTTSの組み合わせ。完全な会話リップシンク、商品別動画、キャスト固有の長編ストーリー、専用衣装/背景の制作は追加工程。

公開・請求に移る際は、実接続の検証結果、確定した規約、提供事業者の承認、費用、公開URLをまとめてユーザーに提示します。

## リワード広告

現在は30秒100G、日最大1,000Gのテスト動画です。広告配信も収益もありません。ブラウザの視聴heartbeatは広告事業者の真正な報酬証明ではありません。広告事業者の審査・配信契約・同意と報酬通知を統合し、不正対策と収益を検証してから正式版へ移します。Gは現金化・送金・Sへの交換をできなくします。Google Ad ManagerではWeb向けSSVを利用できないため、アプリ用SSVと同等の証明があると扱わないでください。

参考：[Webのリワード広告](https://support.google.com/admanager/answer/9116812?hl=en)、[リワード広告ポリシー](https://support.google.com/admanager/answer/7496282?hl=en)。

## 共有デモと本番の区別

GitHub Pagesの静的共有デモの公開は今回ユーザー承認済み。デモにはAPIキー・ローカルDB・アカウント情報を含めず、自由会話・実請求を動作させない。本番サーバーの運営、実決済、実請求の承認とは別。
