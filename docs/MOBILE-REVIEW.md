# スマートフォンUI/UXの改善記録

更新日：2026-10-10。確認→修正→再操作を実施。

## ループ1：読みやすさ

Noto Sans JP/Zen Maru Gothicへ変更。意味が曖昧な説明カード削除。スマホのプロフィールは名前と好意度に絞り、担当を横並びで選択。必要な注記はフッターと開始前の確認画面へ。390×844、320px幅でキャストと主操作が重ならないことを確認。

## ループ2：ボタンと遷移

下部固定の日本語ナビ、上部残高、44px以上の操作、16pxフォーム、音声を主ボタンへ。無料会話と映像設定は折りたたみ。視聴から移動すると取消、他エリアではマイクと接客動画を停止。

エリア切替時に見出しが固定ヘッダーの下へ隠れる問題を発見し、画面上端へ移動する方式へ修正。320pxで横にはみ出す最小幅を修正。視聴途中の画面切替で古いコールバックが報酬を付与しないよう世代管理を追加。

実操作：30秒視聴で89G→189G、S変化なし。途中移動ではG変化なし。G不足のギフト確認は注文不可でG獲得ボタンへ遷移。無料ストーリー完了で好意度4→14、S変化なし。

## ループ3：音声と映像

18本の表情動画を事前生成し、2プレイヤーを重ねてループ。MP4をストリーミング・Range配信。オフ画面とページ非表示では動画を止める。担当変更で前の音声と再生ボタンをリセット。生成済み27音声はGeminiのみ。ルナ・レイナの挨拶再生、停止、返答の聞き直しを確認。

実APIでFal Whisperのdata URL拒否を発見して、期限付きアップロードへ修正。生成AIのJSON囲みをセリフとして読む問題を厳密なJSON解析で修正。最新の自由会話は約36秒。速度はまだ改善が必要。

## ループ4：テストを止めない残高・マイク

既存ローカルアカウントを50,000G・2,000Sまで補充。台帳にテスト通貨として記録、実請求なし。ブラウザ表示で補充を確認し、ギフト購入でGのみ1,500減り、好意度とGemini乾杯音声が反映されることを確認。

小さい声の検出閾値、発話終わりのヒステリシス、音量補正、マイク入力メーター、手動送信を追加。ブラウザでマイク開始後「聞いています」とメーター変動を確認。停止時S変化なし。人間の発話を実際に認識する品質は、利用者のマイクでの確認が必要。
